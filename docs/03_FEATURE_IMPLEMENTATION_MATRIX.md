## 1. Controlled Status Taxonomy Reference

Every feature evaluated in this matrix is graded across all architectural layers using the following controlled status vocabulary:

- **`NOT_STARTED`**: No code or schema implemented.
- **`PLANNED`**: Scheduled for future development.
- **`PARTIALLY_IMPLEMENTED`**: Implemented in some layers (e.g. backend route exists, but frontend UI missing).
- **`IMPLEMENTED`**: Implemented across required layers, but lacking dedicated automated verification.
- **`IMPLEMENTED_AND_TESTED`**: Implemented across stack and validated with passing automated test scripts.
- **`NEEDS_GROOMING`**: Implemented and tested, but heuristic thresholds, UX ergonomics, or external integration requires refinement.
- **`PRODUCTION_READY`**: Fully hardened, tested, documented, and production deployable.
- **`BLOCKED`**: Blocked by external third-party infrastructure (e.g. telecom DLT registration).
